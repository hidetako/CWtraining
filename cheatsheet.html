ラバースタンプ交信の型

自分CQ を出す QRL?  →  CQ CQ CQ DE 自局 自局 自局 PSE K QRL? は「使用中ですか」の確認。返事が無ければ CQ。コールは 3 回。
相手呼んでくる 自局 DE 相手局 相手局 K
自分第 1 交換（レポート・名前・QTH） 相手局 DE 自局 = GE OM TNX FER CALL = UR RST 599 599 = NAME TARO TARO = QTH UEDA UEDA = JCC 0903 = HW? 相手局 DE 自局 K 大事な語は 2 回。GM 朝 / GA 昼 / GE 夜。= は BT（区切り）。HW? で相手に渡す。
相手第 1 交換（相手のレポート・名前・QTH） 自局 DE 相手局 = R R FB = UR RST 599 = NAME BOB = QTH BERLIN = RIG IC-7300 PWR 100W = ANT DP = HW? 自局 DE 相手局 K
自分第 2 交換（設備・天気）→ 締めの合図 相手局 DE 自局 = R R FB BOB ALL SOLID = MY RIG IC-7300 PWR 50W = ANT DP = WX FINE ES TEMP 25C = TNX FER NICE QSO ES 73 = 相手局 DE 自局 K ALL SOLID = 全部取れた。TNX FER NICE QSO ES 73 が「そろそろ終わり」の合図。

短い BK 調（識別を省く速いやり取り）
