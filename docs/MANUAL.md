## 1. アプリを開く

インストールは不要です。ブラウザで開くだけで動きます。
使い方は 3 通りあり、**方法 A が最も簡単**です。

### 方法 A: 公開ページを開く（推奨）

次の URL をブラウザで開きます。

```
https://hidetako.github.io/CWtraining/
```

これだけです。ダウンロードもインストールも要りません。
よく使うならブックマークしておいてください。

> 公開ページが用意されていない場合は、方法 B か C を使ってください。

### 方法 B: ファイルを取得してローカルで開く

インターネットに繋がらない環境で使いたい場合や、
自分で中身を変えたい場合はこちらです。

**1. ファイルを入手する**

GitHub のページ（https://github.com/hidetako/CWtraining）を開き、
緑色の **Code** ボタン → **Download ZIP** を選んで保存し、展開します。

`git` を使える場合は次のコマンドでも取得できます。

```bash
git clone https://github.com/hidetako/CWtraining.git
cd CWtraining
```

**2. 簡易サーバーを起動する**

展開したフォルダの中で、次のいずれかを実行します。

| 環境 | コマンド |
|---|---|
| Python が入っている（macOS / Linux は標準） | `python3 -m http.server 8000` |
| Windows で Python | `py -m http.server 8000` |
| Node.js が入っている | `npx serve -l 8000` |

**3. ブラウザで開く**

```
http://localhost:8000/
```

止めるときは、コマンドを実行した画面で `Ctrl` + `C` を押します。

### 方法 C: VS Code の Live Server

VS Code を使っている場合は、拡張機能「Live Server」を入れて、
フォルダを開き `index.html` を右クリック →
**Open with Live Server** が一番手軽です。

### なぜ `index.html` を直接開くと動かないのか

エクスプローラーや Finder で `index.html` をダブルクリックすると、
`file://` という形式で開かれます。この形式ではブラウザの安全上の制限により
**プログラムの読み込みが拒否され、画面が真っ白になります**。

このアプリは複数のプログラムファイルに分かれているため、
`http://` で配信する必要があります。方法 B のように簡易サーバーを
経由するのは、そのためです。

画面が真っ白なときは、アドレス欄が `file://` で始まっていないか確認してください。

### 画面の大きさについて

**パソコンでの利用を前提にしています。**
画面の右側をパドル欄に固定して常に出しているため、
横幅は 1000 ピクセル以上あると快適です。

スマートフォンやタブレットでも開けますが、表示の切り替えは持っていません。
狭い画面では本文が窮屈になります。

### 動作するブラウザ

Chrome / Edge / Firefox / Safari の、いずれも最近のバージョンで動きます。
Internet Explorer には対応していません。

音を鳴らすために Web Audio API を使っているため、
音が出ない場合は[14. 困ったとき](#14-困ったとき)を参照してください。

## 2. 最初にすること

### 音を出す

ブラウザは、利用者が何か操作するまで音を鳴らせない決まりになっています。
**最初にボタンをひとつ押すまで無音です**。故障ではありません。
どのボタンでも構わないので、まず一度押してください。

音量は画面上部の「音量」で調整します。イヤホンの使用をおすすめします。
CW の練習では、雑音の中から信号を拾う耳を育てるため、音量は控えめのほうが効果的です。

### 自局の情報を入れる

「設定・記録」タブを開き、少なくとも**コールサイン・名前・QTH** を入れてください。
交信シミュレーターやコンテストで、あなたが送信する内容に使われます。

まだコールサインを持っていない場合は、初期値の `JA1ABC` のままで構いません。

| 項目 | 例 | 使われる場面 |
|---|---|---|
| コールサイン | `JA1ABC` | すべての送信 |
| 名前 (NAME) | `TARO` | 交信の第 1 交換 |
| QTH | `TOKYO` | 交信の第 1 交換 |
| リグ (RIG) | `IC-7300` | 交信の第 2 交換 |
| 出力 (PWR) | `50W` | 交信の第 2 交換 |
| アンテナ (ANT) | `DP` | 交信の第 2 交換 |
| 天気 (WX) | `FINE` | 長い交信のとき |

ローマ字の大文字で入れてください（小文字で入れても自動で大文字になります）。

### 速度を合わせる

画面上部の「文字速度」と「実効速度」を、**自分が余裕をもって聞き取れる速さ**まで
下げてください。最初は文字速度 20 WPM・実効速度 8〜10 WPM あたりが目安です。

この 2 つの違いは重要なので、[12. 速度の考え方](#12-速度の考え方)で詳しく説明します。
先に読んでおくと上達が速くなります。

## 3. どこから始めるか（習熟度別）

### まったくの初心者（符号を覚えていない）

1. **聞き取りドリル**の「コッホ法」から始めます。2 文字だけの練習です
2. 正答率 90% を超えたら 1 文字増やす、を繰り返します
3. 10 文字ほど覚えたら、**交信シミュレーター**の「ガイド付き模擬交信」で
   交信の型を眺めてみてください。符号が全部取れなくても構いません
4. 並行して**略語集**を眺め、`CQ` `DE` `RST` `QTH` `73` あたりの意味を覚えます

### 符号は読めるが、交信したことがない

1. **交信シミュレーター**の「ガイド付き模擬交信」を数回通します。
   何をどの順で送るのかが身につきます
2. 「相手の反応」を**おまかせ**にして、聞き返しや取り違えへの対処を練習します
3. 慣れたら「聞き取り練習」に切り替え、書き取りで採点を受けます
4. 送信側は**パドル送信**タブのチュートリアル（13 手順）を通します

### 交信はできるが、コンテストは未経験

1. **コンテスト運用**の「シングルコール」で、F キーの操作に慣れます
2. 「パイルアップ」に移り、アクティビティを 1〜2 から少しずつ上げます
3. QRN・QSB・LID を順に入れて、悪条件に慣れます
4. 「WPX コンテスト」で 30 分の通し運用に挑戦します

## 4. 画面の見方

### 上部（どのタブでも常に操作できます）

| 表示 | 意味 |
|---|---|
| 文字速度 | 一つ一つの文字を打つ速さ（5〜40 WPM） |
| 実効速度 | 文字間・語間を含めた全体の速さ（5〜40 WPM） |
| 音量 | 出力音量（0〜100） |
| ❙❙ 一時停止 | 再生中の音をその場で止めます。もう一度押すと続きから再開します |
| ■ 終了 | 今開いているタブの練習を終わらせ、開始前の状態に戻します |

実効速度は文字速度より速くできません。文字速度を下げると実効速度も一緒に下がります。

### 一時停止・再開・終了

この 2 つのボタンは、どのタブでも同じように効きます。

**一時停止**は、鳴っている音を途中で止めます。音を作る時計ごと止めているので、
再開すると符号の途中からそのまま続きます。速い符号を追いきれなくなったときや、
席を外すときに使ってください。一時停止中は本文が少し暗くなります。

**終了**は、その練習自体をやめます。タブごとに次のように動きます。

| タブ | 終了したときの動き |
|---|---|
| 交信シミュレーター | 交信を打ち切り、開始前の画面に戻ります |
| 聞き取りドリル | 出題をやめます。連続出題の途中なら、そこまでの成績をまとめて表示します |
| コンテスト運用 | 運用を終了し、結果を集計します（「終了」ボタンと同じ） |
| パドル送信 | 打った符号と採点結果を消します |

キーボードでも操作できます。`Space` で一時停止／再開、`Esc` で終了です。
入力欄やボタンの上にカーソルがあるときは、文字入力の邪魔をしないよう効きません。
コンテスト運用ではこの 2 つのキーを別の用途（コールサイン補完・送信中止）に
使っているため、キーボードショートカットは効きません。画面上部のボタンは使えます。

### 画面右のパドル欄

ヘッダーとタブの下から画面下端まで、右側はパドル欄です。
どのタブを開いていてもここに出ています。**打面はこの 1 か所だけです。**

- **打面** — 左半分が左ボタン、右半分が右ボタン。クリックで打電します
  （パドルを接続していれば、そのまま握って打てます）
- **送信速度** — パドル送信タブのつまみと同じものです。どちらを動かしても揃います
- **打った符号** — 打鍵の解読結果が出ます。「消す」で消えます
- **要素の流れ** — 打面のすぐ下に、送出中の `・` `－` が流れます
- **一番下の説明** — 今どの範囲でパドル入力を受け付けているかを示します

たたむ操作はありません。常に出ている前提の配置です。
ヘッダーとタブは常に見えたままで、本文とパドル欄がそれぞれ内側でスクロールします。
なお、この画面はパソコンでの利用を前提にしています。

### タブ

| タブ | 内容 |
|---|---|
| 交信シミュレーター | 交信の型を覚える／聞き取って書き取る |
| 聞き取りドリル | 文字・コールサイン・略語などの反復練習 |
| コンテスト運用 | パイルアップを捌く実戦練習 |
| パドル送信 | エレクトロニックキーヤーで打つ練習 |
| 変換・電鍵 | 任意の文章をモールスに変換／縦振り電鍵の練習 |
| 略語集 | Q 符号・略語 69 語の対訳 |
| 設定・記録 | 自局情報・音の設定・学習の記録 |

## 5. 交信シミュレーター

呼び出しから `73` で終わるまで、定型的な交信（ラバースタンプ QSO）を一通り体験します。
習熟度に応じて 3 つのスタイルがあります。型を覚える「ガイド付き」、
自分の送信を実際にパドルで打つ「実技」、書き取りに徹する「聞き取り練習」で、
上から順に進むのがおすすめです。

### ガイド付き模擬交信（型を覚える段階）

各段階で「今どの局面か」「何のための送信か」が表示されます。

**自分が送る番** では、3 つの選択肢から正しいものを選びます。
選ぶと、正解だけでなく他の選択肢がなぜ駄目なのかも表示されます。
初心者が実際にやりがちな誤り（相手のコールサインを付け忘れる、
まだ続くのに `<SK>` を打ってしまう、など）が選択肢になっています。

選んだあと、「実際に送る内容」の下に **「パドルで打ってみる」** の枠が出ます。
その内容を自分で打てるかを、その場で試せます。

- 画面右のパドル欄の左右をクリック、またはキーボードの
  `Z`（短点側）/ `X`（長点側）で打ちます。打った符号は解読されて欄に出ます
- 「お手本と照合する」で、打った符号と手本を文字単位で照合します
- 「打ち直す」でやり直せます

この枠は**任意**です。打たずに「送信して次へ」で進んでかまいません。
型を覚える段階では選択肢に集中し、慣れてきたら打鍵も試す、という使い方ができます。
打鍵の成績を記録に残したいときは「実技」モードを使ってください。

**相手が送る番** では、まず音だけが流れます。
「内容を見る」を押すと、本文・用語の意味・**その反応が何を意味し、
次に何をすべきか**が表示されます。

### 実技（パドルで打つ）

解説を見ながら、**自分の送信は実際にパドルで打つ**モードです。
呼び出しから `73` までを通しで運用します。

- 各ターンで「打つ内容」が表示され、画面右のパドル欄、または
  キーボードの `Z`（短点側）/ `X`（長点側）で打ちます。
  打った符号はその場で解読されて表示されます
- 「送信を終える（採点）」で、打った符号と手本を文字単位で照合します。
  納得がいかなければ「もう一度打つ」でやり直せます
- 「お手本を聞く」でその送信の正しい音を確認できます
- 相手の送信はガイド付きと同じ流れ（聞く → 内容と意味を見る）です
- 終了時に、自分の送信の平均一致率が表示されます

### 聞き取り練習（実力を試す段階）

相手の送信を聞き取り、ログシートに書き取ります。
**受信中は相手の送信を画面に出しません**（初期設定）。
流れている文字や語の意味が見えると、書き取りの答えがそのまま分かってしまうためです。

どうしても追えないときは、モード選択の下にある
「聞き取り練習で、受信中に相手の送信を表示する」を入にしてください。
この切り替えは聞き取り練習のときだけ出ます。実力を試すときは切のままにしてください。

書き取る項目は交信の長さによって変わります。

- コールサイン
- RST（自局が受けたレポート）
- 相手の名前 / QTH
- リグ / 出力 / アンテナ（標準以上）
- 天気（長いとき）

「答え合わせして次へ」で項目ごとに採点されます。
`5NN` は `599` を短く打つ送り方なので、どちらで書いても正解になります。
空白やハイフンの有無も区別しません。

聞き取りの途中では次のボタンが使えます。

- **もう一度** — 同じ速度で再生し直します
- **ゆっくり** — 5 WPM ほど落として再生します

### 設定項目

| 項目 | 内容 |
|---|---|
| 進め方 | 自分から CQ を出す／相手の CQ に応答する |
| 交信の長さ | 短い（RST・名前・QTH）／標準（＋リグ・アンテナ）／長い（＋天気） |
| 相手の反応 | 型どおり／おまかせ／個別指定 |

### 相手の反応

実際の交信は型どおりに進むとは限りません。「おまかせ」にすると毎回変わります。

| 反応 | 相手の送信 | あなたがすること |
|---|---|---|
| 名前を聞き返される | `PSE NAME AGN?` | 名前だけを繰り返す（全部送り直さない） |
| ゆっくり頼まれる | `QRS PSE QRS` | 速度を落として送り直す |
| コールサインを取り違えられる | 別のコールで呼ばれる | 自分のコールを繰り返して訂正する |
| 呼び出しを取ってもらえない | `QRZ?` | 自分のコールをもう一度打つ |
| 手短に切り上げたい | `SRI QRU PSE 73` | 設備の話は省いて締めに向かう |

### 型の早見表

パネル内の「ラバースタンプ交信の型」を開くと、呼び出しから締めまでの
6 段階について、送信例・各語の意味・その段階のコツがまとめてあります。
送信例にはあなたのコールサインが当てはめられます。
交信中でも開けるので、迷ったら参照してください。

## 6. 聞き取りドリル

短い符号を繰り返し聞いて書き取る、反復練習です。

### 種類

| 種類 | 内容 |
|---|---|
| コッホ法（文字） | 決まった順序で、使う文字を少しずつ増やしていく |
| 頻度順（文字） | 英文での出現頻度が高い文字から増やしていく |
| コールサイン | 実在しそうなコールサインを聞き取る |
| 略語・Q 符号 | 交信で頻出する略語。答え合わせで意味も表示 |
| 数字・RST | RST や番号などの数字列 |
| 頻出単語 | 交信でよく使う短い単語 |
| 苦手集中 | 正答率の低い文字を重点的に出題（記録から自動選択） |

### コッホ法の進め方

CW 学習で最も確実とされる方法です。

1. **レベル 2**（`K` と `M` の 2 文字だけ）から始めます
2. 「出題する」を押すと 5 文字 × 5 群が流れます
3. 聞こえたまま入力して `Enter` を押します
4. **正答率 90% を超えたら**「レベルを 1 上げる」が出るので、1 文字増やします
5. 全 41 文字まで、これを繰り返します

大事な原則が 2 つあります。

- **速度は下げない。** 文字速度は最初から本番と同じ（20 WPM 以上）にして、
  実効速度だけを下げてください。遅い符号で覚えると、速くなったときに
  一から覚え直しになります
- **考えない。** 反射で分かるまで繰り返します。「トン・ツー だから A」と
  数えているうちは、まだレベルを上げないでください

文字順は `K M R S U A P T L O W I . N J E F 0 Y , V G 5 / Q 9 Z H 3 8 B ? 4 2 7 C 1 D 6 X =` です。
似た符号が早い段階で隣り合うよう並んでいるため、この順序に意味があります。

### 連続出題

「連続出題」を 5 / 10 / 20 問にすると、`Enter` だけで
「採点 → 次の問題」が続き、最後に平均正答率とそのセッションで
崩れた文字のまとめが出ます。

### 苦手集中

「設定・記録」タブの「苦手な文字」にある**この文字を集中練習する**を押すと、
正答率の低い文字を重点的に混ぜたドリルがすぐ始まります。
正答率が低い文字ほど多く出題されます。

### 採点の見方

正しく取れた文字は緑、誤った文字は赤で表示されます。
入力が足りない場合は空欄として誤り扱いになります。
正解とそのモールス表記も併せて表示されます。

## 7. コンテスト運用

CQ を出すと複数の局が同時に呼んでくる、実戦形式の練習です。
相手は状態を持ったオペレーターとして動くので、**取り違えれば訂正を求め、
待たせすぎれば諦めて去ります**。

### 運用モード

| モード | 内容 |
|---|---|
| パイルアップ | CQ に複数局が同時に応答。取る力を鍛える基本モード |
| シングルコール | 1 交信につき 1 局だけ。操作に慣れるためのモード |
| WPX コンテスト | 条件固定・30 分。得点 = 有効 QSO × マルチ（プリフィックス数） |
| HST 競技 | IARU 高速電信競技の形式。妨害の無い条件で速度と正確さを競う |

WPX と HST は条件と時間が規定で固定されるため、設定欄が変更できなくなります。

### 一交信の流れ

1. `F1` で **CQ** を出します（開始時は自動で出ます）
2. 呼んできた局のコールサインを聞き取り、**コールサイン欄**に入力します
3. `F2`（または `Enter`）で、そのコールに向けて **`5NN` + ナンバー** を送ります
   - 正しく取れていれば、相手が `R 5NN 042` のように返してきます
   - **惜しいが違う** 場合、相手は自分のコールを打ち直して訂正を促します
   - 全く違う場合、誰も応答しません
4. 相手のナンバーを **受信ナンバー欄** に入力します
5. `F3`（または `Enter`）で **TU** を送り、交信を確定してログに記録します
6. 自動で次の CQ に移ります

### ファンクションキー

| キー | 動作 |
|---|---|
| `F1` | CQ |
| `F2` | 相手のコールとナンバーを送信 |
| `F3` | TU（交信確定・ログ記録） |
| `F4` | 自局コールサイン |
| `F5` | 相手コールサイン |
| `F6` | QSO B4（重複交信の指摘） |
| `F7` | `?`（もう一度名乗ってもらう） |
| `F8` | `NR?`（ナンバーを打ち直してもらう） |

### そのほかの操作

| キー | 動作 |
|---|---|
| `Enter` | 状況に応じて F2 / F3（相手が応答済みなら確定） |
| `Space` | 部分入力したコールサインを、呼んでいる局から補完 |
| `Tab` | 入力欄の移動 |
| `Esc` | 送信を止めて入力欄を消去 |
| `↑` `↓` | RIT を回す（20 Hz ずつ） |
| `PgUp` `PgDn` | 自局の送信速度を ±2 WPM（10〜28 WPM。画面のボタンでも可） |

### 受信のつまみ

複数の局が同時に呼んでくるとき、これらを使って 1 局を選び出します。

- **RIT（同調ずれ）** — ±500 Hz。回すと、周波数のずれた局ほど音程が大きく動きます。
  狙った局の音程を、フィルタの中心に持ってくるのに使います
- **受信帯域幅** — 100〜2000 Hz。絞ると帯域外の局が小さくなります。
  混雑しているときは狭く、探すときは広くします
- **QSK** — オフにすると、自分が送信している間は受信音が絞られます。
  オンのままだと、送信中に呼んできた局も聞こえます

### バンドコンディション

| 項目 | 内容 |
|---|---|
| QRN | 空電（ざーっという雑音） |
| QRM | 別の周波数で CQ を出し続けている局の混信 |
| QSB | フェージング。信号が周期的に浮き沈みする |
| フラッター | 信号がざらつく（極域伝搬などで起きる） |
| LID | 下手な運用者。下記参照 |

**LID** を有効にすると、一部の局が次のような癖を持ちます。実際のコンテストで
遭遇する状況なので、慣れておく価値があります。

- 他局の交信中に割り込んで呼ぶ
- 符号を打ち間違える
- ありえない RST（`339` など）を送ってくる
- 正しく取ったのに訂正を求めてくる
- 自分宛でないのに応答してしまう
- 何度も同じことを繰り返す

### 採点

ログの各行は次の優先順位で判定されます。

| 判定 | 意味 |
|---|---|
| 該当局なし (NIL) | そのコールサインの局は呼んでいなかった |
| コールサイン違い | 取り違えた |
| 重複交信 (DUP) | 既に交信済みの局 |
| RST 違い | RST の取り違え |
| ナンバー違い | ナンバーの取り違え |

終了時に **素点**（打ち込んだ全交信）と **確定点**（誤りを除いたもの）が
並べて表示されます。毎時ペースは直近 5 分間の窓で算出します。
5 分ごとの交信数がヒストグラムで表示され、モードごとの自己ベストも残ります。

### 録音

「この運用を録音する」にチェックを入れて開始すると、運用中の音がそのまま録音され、
終了時に「録音を保存」ボタンが出ます。あとから聞き返して、
取り逃した局が実際どう聞こえていたかを確認できます。

## 8. パドル送信

エレクトロニックキーヤーで実際に打つ練習です。
**パドルをマウスのクリック信号に変換して接続している環境**を想定していますが、
キーボードやタッチ画面でも練習できます。

### 入力方法

| 環境 | 短点 | 長点 |
|---|---|---|
| マウス（右手用） | 左ボタン | 右ボタン |
| マウス（左手用） | 右ボタン | 左ボタン |
| キーボード | `Z` | `X` |
| タッチ画面 | 打面の左半分 | 打面の右半分 |

**打面は画面右のパドル欄だけです。** どのタブを開いていてもここで打てます。
左半分が左ボタン、右半分が右ボタンに対応し、押している側が点灯します。
今どちらのボタンがどちらの要素かは、それぞれの半面に書いてあります。
迷ったらそこを見てください。

交信シミュレーターの実技モードや、ガイド付きの「パドルで打ってみる」も、
同じこの欄で打ちます。

### まずチュートリアルを

パネル先頭に **13 手順のチュートリアル**があります。実際に打って条件を満たすと
自動で次に進みます。

1. パドルとエレクトロニックキーヤー
2. 短点を連続で出す
3. 長点を連続で出す
4. 1 文字打ってみる — A（・－）
5. 逆の順で — N（－・）
6. スクイーズ（両方を握る）
7. モード A と B の違い
8. 速度（WPM）の合わせ方
9. ウェイトの調整
10. 右手用と左手用
11. 語を打つ — CQ
12. 自局のコールサインを打つ
13. 基本は以上です

### 設定

**利き手** — パドルを同じ向きに置いたまま、右手で操作すると左のレバーに親指が、
左手で操作すると右のレバーに親指が当たります。CW では親指を短点に割り当てるのが
一般的なため、左手で打つ場合は短点と長点の割り当てが逆になります。

「親指側を長点にする」と組み合わせると、4 通りから選べます。

| 利き手 | 親指 | 左ボタン | 右ボタン |
|---|---|---|---|
| 右手用 | 短点 | 短点 | 長点 |
| 左手用 | 短点 | 長点 | 短点 |
| 右手用 | 長点 | 長点 | 短点 |
| 左手用 | 長点 | 短点 | 長点 |

**キーヤーモード**

| モード | 動作 |
|---|---|
| アイアンビック B | 両方を離した後にもう 1 要素送出する。多くの市販キーヤーの既定値 |
| アイアンビック A | 余分な要素を出さない。離した時点で送出中の要素を最後に停止 |
| ウルティマチック | 両押しでは後から押した側が優先され、連続送出される |
| 縦振り電鍵 | 左ボタンのみ。押した長さで短点・長点を判定する |

**ウェイト**（35〜65%）— 音を出している時間と休んでいる時間の比率です。
50% が標準。上げると重く、下げると軽い響きになります。全体の速度は変わりません。
実際の交信では 45〜55% に収めるのが無難です。

**送信音の高さ**（400〜1000 Hz）— 打鍵の側音の高さです。受信音の高さ
（設定・記録タブの「側音の高さ」）とは独立しているので、実際の運用と同じように
受信と送信で違う音程にできます。交信シミュレーターで自分の送信を再生するときも
この高さで鳴ります。

**速度**（5〜28 WPM）— まず正確に打てる速度まで落としてください。
速く打ち崩すより、遅くても崩れないほうが相手に届きます。

上限を 28 WPM にしてあるのは、パドルを手で操作して崩れずに打てる範囲に
練習を収めるためです。コンテスト運用の「自局速度」も同じ上限で頭打ちになります
（相手局の速度はこの上限とは別で、それより速い局も出てきます）。

**画面全体でパドル入力を受け付ける** — このタブを開いている間、パドル欄の外を
クリックしても打電できます。ボタンや入力欄の上は通常のクリックとして動きます。

### 課題と採点

「課題」でコールサイン・略語・定型文などの手本を出し、それを打ちます。
「採点する」で、打った符号と手本を文字単位で照合します。

- 緑 — 一致
- 赤の取り消し線 — 打ち漏らし
- 橙の波線 — 余分・誤り

「自由練習」を選ぶと手本なしで、打った符号の解読結果だけが表示されます。

解読できない符号は `＊` で表示されます。文字の区切りは手を止めた時間で
判断しているので、文字と文字の間は短点 3 個分ほど止めてください。

## 11. 設定・記録

### 音の設定

| 項目 | 範囲 | 内容 |
|---|---|---|
| 側音の高さ | 400〜1000 Hz | 受信音の音程。600〜700 Hz が一般的。送信音はパドル送信タブで別に設定 |
| 空電 QRN | 0〜100% | ざーっという雑音 |
| フェージング QSB | 0〜100% | 信号の浮き沈み |
| 混信 QRM | 0〜100% | 別の信号の混入 |
| 側音の波形 | サイン/三角/矩形 | 音色の好みで。矩形は硬い音になります |
| キーイングの立ち上がり | 2/5/8 ms | 短いほどカチッと、長いほど柔らかい鳴り方 |

QRN・QSB・QRM は、ドリルや交信シミュレーターに悪条件を加えるためのものです。
最初は 0 のまま、慣れてきたら少しずつ上げてください。
（コンテスト運用のバンドコンディションは、コンテストタブ側で個別に設定します）

### 表示の設定

- **再生中に本文を表示する** — 答えが見えるので、練習ではオフにしてください
- **初心者モード** — 送信中の Q 符号・略語をリアルタイムで解説します。
  受信中も語の意味が出るため、聞き取りの答えが部分的に見えます。
  実力を試すときはオフにしてください

### 学習の記録

ドリル・交信・送信・コンテストの成績が集計されます。

**上達の推移** には、ドリル正答率・コッホ法レベル・交信/送信成績の
小さな折れ線が表示されます（練習 3 回以上で出現）。点に触れると値が出ます。

**苦手な文字** には、5 回以上出題された文字のうち正答率の低いものが並びます。
「この文字を集中練習する」を押すと、その場で重点ドリルが始まります。

記録はこの端末のブラウザ内（localStorage）にのみ保存されます。
外部には一切送信されません。

**別の端末・ブラウザへ移すには**、「記録を書き出す」で JSON ファイルを保存し、
移動先で「記録を読み込む」を押してそのファイルを選びます。
設定・成績・自己ベストがまとめて移ります。

「記録を消去する」で全部消えます。取り消せません。

## 12. 速度の考え方

CW 学習で最も大事な考え方なので、独立した章にしています。

### 2 つの速度

**文字速度（char WPM）** — 一つ一つの文字を打つ速さ
**実効速度（effective WPM）** — 文字間・語間を含めた、全体としての速さ

このアプリは ARRL 方式のファーンズワース・タイミングを使っており、
**各文字は速いまま、文字間と語間だけを広げます**。

例えば文字速度 20 WPM・実効速度 10 WPM なら、`A` という文字自体は
20 WPM の速さで「ト・ツー」と鳴りますが、次の文字までの間が長く空くため、
全体としては 10 WPM のペースになります。

### なぜこの方式なのか

初心者がやりがちな失敗は、**全体をゆっくりにして覚えること**です。
5 WPM で覚えた `A` の音は、20 WPM の `A` とは別の音に聞こえます。
そのため速度を上げるたびに覚え直しになり、あるところで頭打ちになります。

文字速度を最初から高く保てば、覚えるのは 1 種類の音だけで済みます。
考える時間は文字間の空白で確保します。慣れてきたらその空白を詰めていけば、
文字の聞こえ方は変えずに速度だけを上げられます。

### 具体的な進め方

1. 文字速度を **20 WPM 以上**に設定し、以後は動かしません
2. 実効速度を、余裕をもって取れる速さ（最初は 5〜8 WPM）に下げます
3. その速度で正答率 90% を安定して超えたら、実効速度を 1〜2 WPM 上げます
4. 実効速度が文字速度に追いついたら、両方を一緒に上げていきます

焦って文字速度を下げないことが、遠回りに見えて最短です。

## 14. 困ったとき

### 画面が真っ白で何も出ない

`index.html` をダブルクリックして開いた場合に起こります。
アドレス欄が `file://` で始まっていたらこれが原因です。

[1. アプリを開く](#1-アプリを開く)の方法 A（公開ページ）か
方法 B（簡易サーバー）で開き直してください。

### 音が出ない

- **まずボタンをひとつ押してください。** ブラウザは利用者の操作があるまで
  音を鳴らせません
- 画面上部の「音量」が 0 になっていないか確認してください
- 端末側の音量・消音設定を確認してください
- 「■ 停止」を押した直後は再生が止まっています。もう一度再生してください

### 速すぎて全く取れない

画面上部の**実効速度**を下げてください。文字速度は下げないでください
（理由は[12. 速度の考え方](#12-速度の考え方)）。

聞き取りドリルなら、レベルを下げて文字数を減らすのも有効です。

### パドル（マウス）が反応しない

- 画面右のパドル欄の中をクリックしてください。ここが唯一の打面です
- 欄の外でも打ちたい場合は、「パドル送信」タブの
  「画面全体でパドル入力を受け付ける」をオンにします
- キーボードの `Z` / `X` は、入力欄やボタンに焦点があると効きません。
  パドル欄をクリックしてから押してください
- 短点と長点が逆なら、「利き手」の設定を確認してください

### 右クリックでメニューが出てしまう

パドル欄の上では右クリックメニューを抑止しています。
欄の外で右クリックした場合は通常どおりメニューが出ます。
「画面全体でパドル入力を受け付ける」をオンにすると、画面全体で抑止されます。

### 送信速度を変えても打鍵の速さが変わらない

キーヤーモードが**縦振り電鍵**になっていないか確認してください。
縦振りモードでは符号の長さは押した時間そのもので決まるため、
送信速度の設定は音に反映されません（短点・長点の判定しきい値にだけ使われます）。
アイアンビック A / B またはウルティマチックに切り替えると反映されます。
チュートリアル中は、この状態になると注意と「戻す」ボタンが表示されます。

### 打った符号が `＊` になる

その符号に対応する文字が無い、という意味です。多くは次の原因です。

- 要素を打ちすぎている（短点を押しっぱなしにして 6 個以上出ているなど）
- 文字の途中で間が空きすぎ、2 文字に分割された
- 文字と文字の間が短すぎ、1 文字につながった

文字の間は短点 3 個分ほど止めるのが目安です。

### コンテストで誰も応答してくれない

- 打ち込んだコールサインが、呼んでいる局のどれとも近くない可能性があります。
  `F7`（`?`）を送ると、呼んでいた局がもう一度名乗ります
- 待たせすぎた局は諦めて去ります。`F1` で CQ を出し直してください

### 設定や記録が消えた

設定と記録はブラウザの localStorage に保存されています。次の場合は消えます。

- ブラウザの閲覧データ（サイトデータ・Cookie）を削除した
- プライベートブラウジング／シークレットウィンドウで使っている
- 別のブラウザ、別の端末で開いた

「記録を書き出す」で残したファイルがあれば、「記録を読み込む」で復元できます。

### 画面が窮屈で見づらい

パソコンでの利用を前提にした画面です。右側をパドル欄が占めるため、
ウィンドウの横幅を 1000 ピクセル以上にすると読みやすくなります。
ブラウザの表示倍率を下げるのも有効です。

### 音が途中で止まったまま動かない

一時停止したままになっていないか、画面上部のボタンを確認してください。
「▶ 再開」と出ていれば一時停止中です。もう一度押すと続きから鳴ります。
一時停止中は本文が少し暗くなります。

## 付録: このアプリについて

- 動作環境: Web Audio API に対応したブラウザ（Chrome / Edge / Firefox / Safari）
- 通信: 一切行いません。設定と記録は端末内にのみ保存されます
- 開き方は[1. アプリを開く](#1-アプリを開く)を参照してください

### 品質確認について

この説明書に書いてある操作は、実際のブラウザを自動操作する試験
（`tests/e2e/`）で一通り動作を確認しています。公開ページに対しても
同じ試験を実行できるようになっているので、「説明書どおりに操作したのに
動かない」という状態は起きにくいはずです。手順は
[README](../README.md#テスト) を参照してください。
