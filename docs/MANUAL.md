## 1. アプリを開く

インストールは不要です。ブラウザで開くだけで動きます。
使い方は 3 通りあり、**方法 A が最も簡単**です。

### 方法 A: 公開ページを開く（推奨）

次の URL をブラウザで開きます。

```
https://hidetako.github.io/CWtraining/
```

これだけです。ダウンロードもインストールも要りません。
よく使うならブックマークしておいてください。

> 公開ページが用意されていない場合は、方法 B か C を使ってください。

### 方法 B: ファイルを取得してローカルで開く

インターネットに繋がらない環境で使いたい場合や、
自分で中身を変えたい場合はこちらです。

**1. ファイルを入手する**

GitHub のページ（https://github.com/hidetako/CWtraining）を開き、
緑色の **Code** ボタン → **Download ZIP** を選んで保存し、展開します。

`git` を使える場合は次のコマンドでも取得できます。

```bash
git clone https://github.com/hidetako/CWtraining.git
cd CWtraining
```

**2. 簡易サーバーを起動する**

展開したフォルダの中で、次のいずれかを実行します。

| 環境 | コマンド |
|---|---|
| Python が入っている（macOS / Linux は標準） | `python3 -m http.server 8000` |
| Windows で Python | `py -m http.server 8000` |
| Node.js が入っている | `npx serve -l 8000` |

**3. ブラウザで開く**

```
http://localhost:8000/
```

止めるときは、コマンドを実行した画面で `Ctrl` + `C` を押します。

### 方法 C: VS Code の Live Server

VS Code を使っている場合は、拡張機能「Live Server」を入れて、
フォルダを開き `index.html` を右クリック →
**Open with Live Server** が一番手軽です。

### なぜ `index.html` を直接開くと動かないのか

エクスプローラーや Finder で `index.html` をダブルクリックすると、
`file://` という形式で開かれます。この形式ではブラウザの安全上の制限により
**プログラムの読み込みが拒否され、画面が真っ白になります**。

このアプリは複数のプログラムファイルに分かれているため、
`http://` で配信する必要があります。方法 B のように簡易サーバーを
経由するのは、そのためです。

画面が真っ白なときは、アドレス欄が `file://` で始まっていないか確認してください。

### 画面の大きさについて

**パソコンでもスマートフォンでも使えます。** 画面の幅で並べ方が変わります。

| 画面の幅 | 並べ方 |
|---|---|
| 760 ピクセルより広く、背も高い | 左に本文、右にパドル欄を常置（パソコン・タブレット） |
| 760 ピクセル以下 | 本文を 1 列にし、パドルは下から出す引き出しにする（スマートフォン） |
| 背が低く、指で操作している | 同上（スマートフォンを横向きにしたとき） |

スマートフォンを横向きにすると幅は 800〜900 ピクセルになりますが、高さが
400 ピクセルほどしかありません。幅だけで決めると 2 列のまま縦に潰れるので、
**背の低い画面も 1 列**にしています。パソコンの窓を低くしただけのときは
2 列のままです。

パソコンでは横幅 1000 ピクセル以上あると、パドル欄と本文の両方に余裕が出ます。

### スマートフォンで使うとき

- パドルは画面右下の **「・－ パドル」** を押すと下から出てきます。
  打面の左半分が短点、右半分が長点です。**指でそのまま打てます**
- パドル送信タブに移ったとき、実技で打鍵の番が来たときは、自動で開きます。
  そのとき「何を打つのか」が引き出しの上に来るよう、本文も一緒に寄せます
- 引き出しは右上の **✕** で畳めます
- 一時停止と終了は、画面の狭さに合わせて記号だけのボタンになります
  （❙❙ と ■）。速度と音量は題名の下で横になぞって出します

**イヤホンの利用をおすすめします。** また、iPhone では**本体側面のサイレント
スイッチが入っていると音が出ません**。音が鳴らないときはまずここを確認してください
（[16. 困ったとき](#16-困ったとき)も参照）。

### 動作するブラウザ

Chrome / Edge / Firefox / Safari の、いずれも最近のバージョンで動きます。
Internet Explorer には対応していません。

音を鳴らすために Web Audio API を使っているため、
音が出ない場合は[16. 困ったとき](#16-困ったとき)を参照してください。

## 2. 最初にすること

### 音を出す

ブラウザは、利用者が何か操作するまで音を鳴らせない決まりになっています。
**最初にボタンをひとつ押すまで無音です**。故障ではありません。
どのボタンでも構わないので、まず一度押してください。

音量は画面上部の「音量」で調整します。イヤホンの使用をおすすめします。
CW の練習では、雑音の中から信号を拾う耳を育てるため、音量は控えめのほうが効果的です。

### 自局の情報を入れる

「設定・記録」タブを開き、少なくとも**コールサイン・名前・QTH** を入れてください。
交信シミュレーターやコンテストで、あなたが送信する内容に使われます。

まだコールサインを持っていない場合は、初期値の `JA1ABC` のままで構いません。

| 項目 | 例 | 使われる場面 |
|---|---|---|
| コールサイン | `JA1ABC` | すべての送信 |
| 名前 (NAME) | `TARO` | 交信の第 1 交換 |
| QTH | `TOKYO` | 交信の第 1 交換 |
| リグ (RIG) | `IC-7300` | 交信の第 2 交換 |
| 出力 (PWR) | `50W` | 交信の第 2 交換 |
| アンテナ (ANT) | `DP` | 交信の第 2 交換 |
| 天気 (WX) | `FINE` | 長い交信のとき |

ローマ字の大文字で入れてください（小文字で入れても自動で大文字になります）。

### 速度を合わせる

画面上部の「文字速度」と「実効速度」を、**自分が余裕をもって聞き取れる速さ**まで
下げてください。最初は文字速度 20 WPM・実効速度 8〜10 WPM あたりが目安です。

この 2 つの違いは重要なので、[14. 速度の考え方](#14-速度の考え方)で詳しく説明します。
先に読んでおくと上達が速くなります。

## 3. どこから始めるか（習熟度別）

### まったくの初心者（符号を覚えていない）

1. **聞き取りドリル**の「コッホ法」から始めます。2 文字だけの練習です
2. 正答率 90% を超えたら 1 文字増やす、を繰り返します
3. 10 文字ほど覚えたら、**交信シミュレーター**の「ガイド付き模擬交信」で
   交信の型を眺めてみてください。符号が全部取れなくても構いません
4. 並行して**略語集**を眺め、`CQ` `DE` `RST` `QTH` `73` あたりの意味を覚えます

### 符号は読めるが、交信したことがない

1. **交信シミュレーター**の「ガイド付き模擬交信」を数回通します。
   何をどの順で送るのかが身につきます
2. 「相手の反応」を**おまかせ**にして、聞き返しや取り違えへの対処を練習します
3. 慣れたら「聞き取り練習」に切り替え、書き取りで採点を受けます
4. 送信側は**パドル送信**タブのチュートリアル（13 手順）を通します

### 交信はできるが、コンテストは未経験

1. **コンテスト運用**の「シングルコール」で、F キーの操作に慣れます
2. 「パイルアップ」に移り、アクティビティを 1〜2 から少しずつ上げます
3. QRN・QSB・LID を順に入れて、悪条件に慣れます
4. 「WPX コンテスト」で 30 分の通し運用に挑戦します

## 4. 画面の見方

### 上部（どのタブでも常に操作できます）

| 表示 | 意味 |
|---|---|
| 文字速度 | 一つ一つの文字を打つ速さ（5〜30 WPM） |
| 実効速度 | 文字間・語間を含めた全体の速さ（5〜30 WPM） |
| 音量 | 出力音量（0〜100） |
| ❙❙ 一時停止 | 再生中の音をその場で止めます。もう一度押すと続きから再開します |
| ■ 終了 | 今開いているタブの練習を終わらせ、開始前の状態に戻します |

実効速度は文字速度より速くできません。文字速度を下げると実効速度も一緒に下がります。

### 一時停止・再開・終了

この 2 つのボタンは、どのタブでも同じように効きます。

**一時停止**は、鳴っている音を途中で止めます。音を作る時計ごと止めているので、
再開すると符号の途中からそのまま続きます。速い符号を追いきれなくなったときや、
席を外すときに使ってください。一時停止中は本文が少し暗くなります。

**終了**は、その練習自体をやめます。タブごとに次のように動きます。

| タブ | 終了したときの動き |
|---|---|
| 交信シミュレーター | 交信を打ち切り、開始前の画面に戻ります |
| 聞き取りドリル | 出題をやめます。連続出題の途中なら、そこまでの成績をまとめて表示します |
| コンテスト運用 | 運用を終了し、結果を集計します（「終了」ボタンと同じ） |
| パドル送信 | 打った符号と採点結果を消します |

キーボードでも操作できます。`Space` で一時停止／再開、`Esc` で終了です。
ただし**打った符号が残っているときの `Esc` は「打ち直す」になります** —
パドルから手を離さずに打ち直せるようにするためです。
打っていない状態でもう一度押せば終了します。
パドル欄はどのタブでも使えるので、聞き取りドリル中に試し打ちした符号も
同じように `Esc` で消せます（そのときドリルは終わりません）。

**打った符号を消す `Esc` は、焦点がどこにあっても効きます。** つまみを
動かした直後でも、ボタンをクリックした直後でも、書き取り欄に文字を
打ち込んでいる最中でも同じです。打面のすぐ下のボタンが「打ち直す（`Esc`）」と
出している以上、効いたり効かなかったりしては困るためです。

一方、**打った符号が無いときの `Esc`（＝練習の終了）は、文字を打ち込んで
いる最中には効きません。** 取り消しの利かない操作なので、書き取りの途中で
誤って終わってしまわないようにしています。

`Space` は文字そのものなので、入力欄の上では効きません。ボタンを押す操作とも
重なるため、ボタンに焦点があるときも効きません。
コンテスト運用ではこの 2 つのキーを別の用途（コールサイン補完・送信中止）に
使っているため、キーボードショートカットは効きません。画面上部のボタンは使えます。

### 画面右のパドル欄

ヘッダーとタブの下から画面下端まで、右側はパドル欄です。
どのタブを開いていてもここに出ています。**打面はこの 1 か所だけです。**

- **打面** — 左半分が左ボタン、右半分が右ボタン。クリックで打電します
  （パドルを接続していれば、そのまま握って打てます）
- **送信速度** — パドル送信タブのつまみと同じものです。どちらを動かしても揃います
- **要素の流れ** — 打面のすぐ下に、送出中の `・` `－` が流れます
- **打った符号** — 打鍵の解読結果が出ます
- **打ち直す** — 打った符号を消します（`Esc` でも同じ）。
  打面のすぐ下に置いてあるので、パドルから手を離してすぐ押せます。
  課題が出ていないときは「消す」という表示になります
- **一番下の説明** — 今どの範囲でパドル入力を受け付けているかを示します

たたむ操作はありません。常に出ている前提の配置です。
ヘッダーとタブは常に見えたままで、本文とパドル欄がそれぞれ内側でスクロールします。
画面が狭いときは 1 列になり、パドルは下から出す引き出しに変わります。

### タブ

| タブ | 内容 |
|---|---|
| 交信シミュレーター | 交信の型を覚える／聞き取って書き取る |
| 聞き取りドリル | 文字・コールサイン・略語などの反復練習 |
| コンテスト運用 | パイルアップを捌く実戦練習 |
| パドル送信 | エレクトロニックキーヤーで打つ練習 |
| 変換・電鍵 | 任意の文章をモールスに変換／縦振り電鍵の練習 |
| 略語集 | Q 符号・略語 90 語＋記号・プロサイン 11 種の対訳 |
| 設定・記録 | 自局情報・音の設定・学習の記録 |

## 5. 交信シミュレーター

呼び出しから `73` で終わるまで、定型的な交信（ラバースタンプ QSO）を一通り体験します。
習熟度に応じて 3 つのスタイルがあります。型を覚える「ガイド付き」、
自分の送信を実際にパドルで打つ「実技」、書き取りに徹する「聞き取り練習」で、
上から順に進むのがおすすめです。

### ガイド付き模擬交信（型を覚える段階）

各段階で「今どの局面か」「何のための送信か」が表示されます。

**自分が送る番** では、3 つの選択肢から正しいものを選びます。
選ぶと、正解だけでなく他の選択肢がなぜ駄目なのかも表示されます。
初心者が実際にやりがちな誤り（相手のコールサインを付け忘れる、
まだ続くのに `<SK>` を打ってしまう、など）が選択肢になっています。

選んだあと、「実際に送る内容」の下に **「パドルで打ってみる」** の枠が出ます。
その内容を自分で打てるかを、その場で試せます。

- 画面右のパドル欄の左右をクリック、またはキーボードの
  `Z`（短点側）/ `X`（長点側）で打ちます。打った符号は解読されて欄に出ます
- 「お手本と照合する」で、打った符号と手本を文字単位で照合します
- 「打ち直す」でやり直せます

この枠は**任意**です。打たずに「送信して次へ」で進んでかまいません。
型を覚える段階では選択肢に集中し、慣れてきたら打鍵も試す、という使い方ができます。
打鍵の成績を記録に残したいときは「実技」モードを使ってください。

**相手が送る番** では、まず音だけが流れます。
「内容を見る」を押すと、本文・用語の意味・**その反応が何を意味し、
次に何をすべきか**が表示されます。

本文が出たあとに聞き直すと、**今どの語を送っているかが順に光ります**。
どこで取りこぼしたのかを目と耳で突き合わせられます。
（聞き取り練習の「本文を聞き直す」、実技の「お手本を聞く」、
変換・電鍵タブの再生でも同じように光ります）

### 実技（パドルで打つ）

解説を見ながら、**自分の送信は実際にパドルで打つ**モードです。
呼び出しから `73` までを通しで運用します。

- 各ターンで「打つ内容」が表示され、画面右のパドル欄、または
  キーボードの `Z`（短点側）/ `X`（長点側）で打ちます。
  打った符号はその場で解読されて表示されます
- 「送信を終える（採点）」で、打った符号と手本を文字単位で照合します。
  納得がいかなければ「もう一度打つ」でやり直せます
- 打ち直したいときは、**パドル欄の「打ち直す」か `Esc`** が手近です。
  本文側のボタンまでポインタを動かす必要はありません
- 「お手本を聞く」でその送信の正しい音を確認できます
- 相手の送信はガイド付きと同じ流れ（聞く → 内容と意味を見る）です
- 終了時に、自分の送信の平均一致率が表示されます

### 聞き取り練習（実力を試す段階）

相手の送信を聞き取り、ログシートに書き取ります。
**受信中は相手の送信を画面に出しません**（初期設定）。
流れている文字や語の意味が見えると、書き取りの答えがそのまま分かってしまうためです。

どうしても追えないときは、モード選択の下にある
「聞き取り練習で、受信中に相手の送信を表示する」を入にしてください。
この切り替えは聞き取り練習のときだけ出ます。実力を試すときは切のままにしてください。

書き取り欄には「聞き取ったコールサインを入力」のように、
その欄に何を入れるのかが薄く表示されます。**その項目だけ**を入れてください
（本文を丸ごと入れる欄ではありません）。

書き取る項目は交信の長さによって変わります。

- コールサイン
- RST（自局が受けたレポート）
- 相手の名前 / QTH
- リグ / 出力 / アンテナ（標準以上）
- 天気（長いとき）

「答え合わせして次へ」で項目ごとに採点されます。
`5NN` は `599` を短く打つ送り方なので、どちらで書いても正解になります。
空白やハイフンの有無も区別しません。

聞き取りの途中では次のボタンが使えます。

- **もう一度** — 同じ速度で再生し直します
- **ゆっくり** — 5 WPM ほど落として再生します

### 設定項目

| 項目 | 内容 |
|---|---|
| 進め方 | 自分から CQ を出す／相手の CQ に応答する |
| 交信の長さ | 短い（RST・名前・QTH）／標準（＋リグ・アンテナ）／長い（＋天気） |
| 相手の反応 | 型どおり／おまかせ／個別指定 |

### 相手の反応

実際の交信は型どおりに進むとは限りません。「おまかせ」にすると毎回変わります。

| 反応 | 相手の送信 | あなたがすること |
|---|---|---|
| 名前を聞き返される | `PSE NAME AGN?` | 名前だけを繰り返す（全部送り直さない） |
| ゆっくり頼まれる | `QRS PSE QRS` | 速度を落として送り直す |
| コールサインを取り違えられる | 別のコールで呼ばれる | 自分のコールを繰り返して訂正する |
| 呼び出しを取ってもらえない | `QRZ?` | 自分のコールをもう一度打つ |
| 手短に切り上げたい | `SRI QRU PSE 73` | 設備の話は省いて締めに向かう |

### 型の早見表

パネル内の「ラバースタンプ交信の型」を開くと、呼び出しから締めまでの
6 段階について、送信例・各語の意味・その段階のコツがまとめてあります。
送信例にはあなたのコールサインが当てはめられます。
交信中でも開けるので、迷ったら参照してください。

## 6. 聞き取りドリル

短い符号を繰り返し聞いて書き取る、反復練習です。

### 種類

| 種類 | 内容 |
|---|---|
| コッホ法（文字） | 決まった順序で、使う文字を少しずつ増やしていく |
| 頻度順（文字） | 英文での出現頻度が高い文字から増やしていく |
| コールサイン | 実在しそうなコールサインを聞き取る |
| 略語・Q 符号 | 交信で頻出する略語。答え合わせで意味も表示 |
| Q 符号だけ | QRM・QSB・QTH など Q 符号にしぼって出題 |
| 数字・RST | RST や番号などの数字列 |
| RST レポート | 599 や 5NN など信号レポートだけ。各桁の意味も表示 |
| 頻出単語 | 交信でよく使う短い単語 |
| 名前 | TAKA・BOB など、交信で名乗る名前 |
| 地名（QTH） | TOKYO・BERLIN など、交信で伝える地名 |
| 設備（RIG・ANT・出力） | IC-7300・3ELE YAGI・50W など、型番の数字とハイフン |
| 交信の定型文 | 実際の交信で送られる一節をまるごと |
| 実戦の一節 | コールサイン・RST・名前・地名を、交信そのままの並びで |
| 記号・プロサイン | `=` `/` `?` `.` `,` や `<AR>` `<SK>` など、ローマ字以外の符号だけ |
| 苦手集中 | 正答率の低い文字を重点的に出題（記録から自動選択） |

**単語ひとつずつが取れても、続けて送られると取れない**ものです。
「交信の定型文」と「実戦の一節」は、その段差を埋めるためのものです。
`UR 599 599 NAME BOB BOB` のように、実際に送られる並びのまま出題します。

### 答え合わせの解説

Q 符号・略語・RST・プロサインが答えに含まれていると、答え合わせに
**意味と符号**が並びます。`QRM 混信を受けている －－・－ ・－・ －－` のように、
何を意味する符号で、どう打つのかを一度に確かめられます。

RST は各桁まで分けて説明します。`599` なら
「了解度 5:完全に了解 / 強度 9:極めて強い / 音調 9:完全な純音」です。
`5NN` は `599` を短く打つ送り方なので、同じ説明が付きます。

複数の語からなる問題では、語ごとに並びます。意味の分からない符号を
覚えないまま繰り返しても身に付かないので、取れた・取れなかったに
かかわらず毎回出ます。

### 記号とプロサイン

ローマ字と数字だけでは交信になりません。話題の切れ目の `=`（BT）、
移動運用の `/`、聞き返しの `?` は、取れないと意味が変わってしまいます。

**記号・プロサイン**のドリルで、これらだけを集中して練習できます。
コッホ法と同じくレベルで少しずつ増やす形で、交信で耳にする頻度の高い順に並びます。

| 順 | 符号 | 意味 |
|---|---|---|
| 1 | `=` | 区切り（BT）— 話題の切れ目 |
| 2 | `/` | 斜線 — 移動運用の地域を添える（`JA1ABC/1` など） |
| 3 | `?` | 「もう一度」「何ですか」 |
| 4 | `.` | ピリオド |
| 5 | `,` | コンマ |
| 6 | `<AR>` | 送信の終わり |
| 7 | `<SK>` | 交信終了 |
| 8 | `<KN>` | 指定局のみどうぞ |
| 9 | `-` | ハイフン（`IC-7300` など） |
| 10 | `<BK>` | ブレークイン |
| 11 | `@` | アットマーク |

**頻度順のドリルにも、数字のあとに同じ並びで入っています。**
文字と数字を覚えたら、そのまま記号まで続けて進められます。

**答えの書き方**: プロサインは `<AR>` のように山かっこで書きます。
書き方を覚えていなくても、答案欄の下に**入力ボタン**が出るので、
そこから入れられます。このボタンは、そのレベルで記号を使うときだけ出ます
（出題された答えに記号があるかどうかでは切り替えません。それだと
ボタンが出ていること自体が答えの手がかりになってしまいます）。

**同じ符号を持つ表記は、どちらで書いても正解です。** `=` と `<BT>` は
どちらも `－・・・－` で、耳では区別が付かないためです。逆に、`<AR>` を
`AR` と 2 文字で書くのは不正解です。音がまったく違います
（`<AR>` は `・－・－・`、`A` `R` は `・－` `・－・`）。

なお `+` は `<AR>` と、`(` は `<KN>` と同じ符号なので、出題には片方だけを
使っています。両方を出すと、聞いても答えが一つに決まりません。

### コッホ法の進め方

CW 学習で最も確実とされる方法です。

1. **レベル 2**（`K` と `M` の 2 文字だけ）から始めます
2. 「出題する」を押すと **3・2・1 と数えてから**流れます
3. 聞こえたまま入力して `Enter` を押します
4. **正答率 90% を超えたら**「レベルを 1 上げる」が出るので、1 文字増やします
5. 全 41 文字まで、これを繰り返します

### 出題までの間

「出題する」を押すと、大きく **3 → 2 → 1** と数えてから符号が流れます。
押した瞬間に鳴ると身構える間が無く、最初の 1 文字を落としやすいためです。
連続出題の「次の問題」でも毎回数えます。

**「もう一度聞く」「ゆっくり再生」は数えません。** すでに構えているので、
押したらすぐ鳴ります。

**再生を押すと、書き取り欄にカーソルが移ります。** そのまま打ち込めるので、
いちいち欄をクリックし直す必要はありません。3 つのボタン（出題する・
もう一度聞く・ゆっくり再生）すべてで同じです。途中まで書いてある内容は
消えず、カーソルは末尾に付くので続きから打てます。

数えている途中で「出題する」を押し直せば数え直し、「終了」を押せば
そのまま止まります（数え終わってから鳴り出す、ということはありません）。

大事な原則が 2 つあります。

- **速度は下げない。** 文字速度は最初から本番と同じ（20 WPM 以上）にして、
  実効速度だけを下げてください。遅い符号で覚えると、速くなったときに
  一から覚え直しになります
- **考えない。** 反射で分かるまで繰り返します。「トン・ツー だから A」と
  数えているうちは、まだレベルを上げないでください

文字順は `K M R S U A P T L O W I . N J E F 0 Y , V G 5 / Q 9 Z H 3 8 B ? 4 2 7 C 1 D 6 X =` です。
似た符号が早い段階で隣り合うよう並んでいるため、この順序に意味があります。

### 連続出題

「連続出題」を 5 / 10 / 20 問にすると、`Enter` だけで
「採点 → 次の問題」が続き、最後に平均正答率とそのセッションで
崩れた文字のまとめが出ます。

`Enter` は「採点する」と「次の問題へ」を兼ねていますが、**採点した直後の
`Enter` は受け付けません**。書き終えた勢いでキーを押し込んだり、少し長く
押したままにすると、採点結果を見ないまま次の問題に移ってしまうためです。
ひと呼吸おいてから押してください。

**「レベルを 1 上げる」を押しても、その場では次の問題に進みません。**
採点結果を見ながらレベルを上げられるようにしてあります。次の問題は
「次の問題」で始めてください。上げた文字は次の問題から入ります。

### 苦手集中

「設定・記録」タブの「苦手な文字（聞き取り）」にある**この文字を集中練習する**を押すと、
正答率の低い文字を重点的に混ぜたドリルがすぐ始まります。
正答率が低い文字ほど多く出題されます。

### 採点の見方

**間違えたときは、自分の答えと正解が上下 2 段に並びます。**

```
あなた  K K M X M M M …
正解    K K M K M M M …
```

1 列が 1 文字で、上下が同じ文字に対応します。桁がそろうので、どこを
書き間違えたのか、どこが抜けたのかを縦に見比べられます。打ち漏らした
ところは自分の側が `—` になります。プロサイン `<SK>` のように文字数の
違う符号も 1 列に収まります。

全問正解のときは 1 段だけの表示です。

文字ごとの色分けは次のとおりです。

| 表示 | 意味 |
|---|---|
| 緑 | 取れた文字 |
| 赤の破線の囲み | 取り漏らした文字（出題にあって解答に無い） |
| 橙の波線 | 書き間違えた文字・余分に入れた文字 |

取り漏らした文字は囲みで示します。字の上に取り消し線を引くと、線が字画と
一体に見えて別の字に読めてしまうためです（`7` が `ｱ`、`3` が `ヨ`、`J` が `チ` に
見えます）。

正解とそのモールス表記も併せて表示されます。

**途中で 1 文字取り漏らしても、それ以降が全部誤りにはなりません。**
出題と解答を単純に頭から突き合わせるのではなく、対応の取れる部分を
探してから過不足を数えているためです。例えば 10 文字のうち先頭の 1 文字だけを
落とした場合は 9/10 と数えられます。

**書き間違いは 1 回の誤りとして数えます。** 落としたときと同じ重さです。
5 文字のうち 1 文字を書き間違えれば 4/5 で 80%、1 文字落としても 80% です。
内訳には「書き間違い 1 文字」と出ます。

一方で、**自信の無いところを埋めるために多めに打つと不利になります**。
書き間違いではない余分（間に挟んだ文字）は分母に数えるので、当てずっぽうで
文字数を増やしても得点は上がりません。内訳には「余分 1 文字（減点）」と出ます。
分からなかったところは空けておいてください。

点数の右には内訳が言葉でも出ます。「12 / 14 文字一致・抜け 2 文字」であれば、
手本の 14 文字のうち 2 文字が出てこなかった、という意味です。手本が
`GB OM ES GL = 73 73 <SK>` のように同じ語を 2 回繰り返す場合、片方だけ打つと
この形で 2 文字分が抜けとして出ます。

## 7. コンテスト運用

CQ を出すと複数の局が同時に呼んでくる、実戦形式の練習です。
相手は状態を持ったオペレーターとして動くので、**取り違えれば訂正を求め、
待たせすぎれば諦めて去ります**。

### 運用モード

| モード | 内容 |
|---|---|
| パイルアップ | CQ に複数局が同時に応答。取る力を鍛える基本モード |
| シングルコール | 1 交信につき 1 局だけ。操作に慣れるためのモード |
| WPX コンテスト | 条件固定・30 分。得点 = 有効 QSO × マルチ（プリフィックス数） |
| HST 競技 | IARU 高速電信競技の形式。妨害の無い条件で速度と正確さを競う |

WPX と HST は条件と時間が規定で固定されるため、設定欄が変更できなくなります。

### 相手局の速度

呼んでくる局がどれくらいの速さで打つかを、自局の速度とは別に決められます。

| 設定 | 範囲 | 内容 |
|---|---|---|
| 相手局の速度 | 10〜45 WPM | 呼んでくる局の速度の基準 |
| 相手局の速度のばらつき | 0〜±12 WPM | 局ごとの散らばり。0 にすると全局が同じ速度になります |

はじめは**ばらつきを 0 にして、確実に取れる速度**から始めてください。
取れるようになったら基準を 1〜2 WPM ずつ上げ、慣れてきたらばらつきを付けて
「速い局も遅い局も混ざる」実戦に近い状態にします。

自局速度（`PgUp` / `PgDn`）とは独立しています。相手が 30 WPM で打ってきても、
自分は 18 WPM で返して構いません。実際の交信でもよくあることです。

運用中に変えても構いません。ただし**すでに呼んでいる局の速度は変わりません**。
次に `F1` で CQ を出したところから、新しい速度の局が現れます。
実際の交信でも相手の手を変えることはできない、という考え方に合わせています。

HST 競技では規定で全局の速度がそろうため、ばらつきは変更できません。

### 難易度（受信ヘルプ）

コンテストは「耳だけで取る」のが本番ですが、いきなりそこへ放り込まれても
何が起きているのか分からないままになります。そこで、相手が送っている内容を
**どこまで画面に出すか**を 3 段階で選べるようにしています。

| 段階 | 表示 | 何を練習する段階か |
|---|---|---|
| 初級 | 送られた内容を順に表示 | 交換の**型**を覚える。何がどの順で飛んでくるかを目で確認します |
| 中級 | いま打たれている 1 文字だけ | 耳で追いながら、その場で答え合わせをします。文字は残りません |
| 上級 | 表示なし | 実際のコンテストと同じ条件です（**既定**） |

**相手のコールサインは、どの段階でも伏せます。** 画面には `？` と出ます。
コールサインは聞き取るべき答えそのもので、出してしまうと練習になりません。
`？` は文字数も伏せるため、何文字であっても 1 つだけ表示されます。
RST・ナンバー・`CQ` `TEST` `DE` `R` `TU` などの定型と、自局のコールサインは
そのまま表示されます。

初級では、打ち終わった内容が**そのまま残ります**。読んでログに打ち込むまでが
一連の作業なので、消えてしまうと使えないからです。`F3`（TU）で交信を確定するか、
`F1` で次の CQ を出したところで片付きます。中級は打ち終わると消えます。

混信局（QRM）の送信は表示しません。読む対象ではなく、妨害として鳴っているだけです。

運用中でも切り替えられます。切り替えると、それまで出ていた行はいったん消え、
次の送信から新しい段階の決まりで表示されます。

**進め方の目安**: 初級で交換の型を覚え、中級で耳を慣らし、上級へ移ります。
上級で取れないときは一段戻して構いません。段階を落とすのは後退ではなく、
取れる速度と条件で回数を積むためです。

### 一交信の流れ

1. `F1` で **CQ** を出します（開始時は自動で出ます）
2. 呼んできた局のコールサインを聞き取り、**コールサイン欄**に入力します
3. `F2`（または `Enter`）で、そのコールに向けて **`5NN` + ナンバー** を送ります
   - 正しく取れていれば、相手が `R 5NN 042` のように返してきます
   - **惜しいが違う** 場合、相手は自分のコールを打ち直して訂正を促します
   - 全く違う場合、誰も応答しません
4. 相手のナンバーを **受信ナンバー欄** に入力します
5. `F3`（または `Enter`）で **TU** を送り、交信を確定してログに記録します
6. 自動で次の CQ に移ります

### ファンクションキー

| キー | 動作 |
|---|---|
| `F1` | CQ |
| `F2` | 相手のコールとナンバーを送信 |
| `F3` | TU（交信確定・ログ記録） |
| `F4` | 自局コールサイン |
| `F5` | 相手コールサイン |
| `F6` | QSO B4（重複交信の指摘） |
| `F7` | `?`（もう一度名乗ってもらう） |
| `F8` | `NR?`（ナンバーを打ち直してもらう） |

### そのほかの操作

| キー | 動作 |
|---|---|
| `Enter` | 状況に応じて F2 / F3（相手が応答済みなら確定） |
| `Space` | 部分入力したコールサインを、呼んでいる局から補完 |
| `Tab` | 入力欄の移動 |
| `Esc` | 送信を止めて入力欄を消去 |
| `↑` `↓` | RIT を回す（20 Hz ずつ） |
| `PgUp` `PgDn` | 自局の送信速度を ±2 WPM（10〜28 WPM。画面のボタンでも可） |

### 受信のつまみ

複数の局が同時に呼んでくるとき、これらを使って 1 局を選び出します。

- **RIT（同調ずれ）** — ±500 Hz。回すと、周波数のずれた局ほど音程が大きく動きます。
  狙った局の音程を、フィルタの中心に持ってくるのに使います
- **受信帯域幅** — 100〜2000 Hz。絞ると帯域外の局が小さくなります。
  混雑しているときは狭く、探すときは広くします
- **QSK** — オフにすると、自分が送信している間は受信音が絞られます。
  オンのままだと、送信中に呼んできた局も聞こえます

### バンドコンディション

| 項目 | 内容 |
|---|---|
| QRN | 空電（ざーっという雑音） |
| QRM | 別の周波数で CQ を出し続けている局の混信 |
| QSB | フェージング。信号が周期的に浮き沈みする |
| フラッター | 信号がざらつく（極域伝搬などで起きる） |
| LID | 下手な運用者。下記参照 |

**LID** を有効にすると、一部の局が次のような癖を持ちます。実際のコンテストで
遭遇する状況なので、慣れておく価値があります。

- 他局の交信中に割り込んで呼ぶ
- 符号を打ち間違える
- ありえない RST（`339` など）を送ってくる
- 正しく取ったのに訂正を求めてくる
- 自分宛でないのに応答してしまう
- 何度も同じことを繰り返す

### 採点

ログの各行は次の優先順位で判定されます。

| 判定 | 意味 |
|---|---|
| 該当局なし (NIL) | そのコールサインの局は呼んでいなかった |
| コールサイン違い | 取り違えた |
| 重複交信 (DUP) | 既に交信済みの局 |
| RST 違い | RST の取り違え |
| ナンバー違い | ナンバーの取り違え |

終了時に **素点**（打ち込んだ全交信）と **確定点**（誤りを除いたもの）が
並べて表示されます。毎時ペースは直近 5 分間の窓で算出します。
5 分ごとの交信数がヒストグラムで表示され、モードごとの自己ベストも残ります。

### 録音

「この運用を録音する」にチェックを入れて開始すると、運用中の音がそのまま録音され、
終了時に「録音を保存」ボタンが出ます。あとから聞き返して、
取り逃した局が実際どう聞こえていたかを確認できます。

## 8. パドル送信

エレクトロニックキーヤーで実際に打つ練習です。
**パドルをマウスのクリック信号に変換して接続している環境**を想定していますが、
キーボードやタッチ画面でも練習できます。

### 入力方法

| 環境 | 短点 | 長点 |
|---|---|---|
| マウス（右手用） | 左ボタン | 右ボタン |
| マウス（左手用） | 右ボタン | 左ボタン |
| キーボード | `Z` | `X` |
| タッチ画面 | 打面の左半分 | 打面の右半分 |

**打面は画面右のパドル欄だけです。** どのタブを開いていてもここで打てます。
左半分が左ボタン、右半分が右ボタンに対応し、押している側が点灯します。
実物のパドルと同じく左右のレバーは接触していて、境界は中央の仕切り線と
面の色の違いで見分けます。
今どちらのボタンがどちらの要素かは、それぞれの半面に書いてあります。
迷ったらそこを見てください。

交信シミュレーターの実技モードや、ガイド付きの「パドルで打ってみる」も、
同じこの欄で打ちます。

#### 打鍵が止まらなくなったら

パドルに触っていないのに短点（または長点）が入り続けることがありました。
ブラウザに「離した」という合図が届かないと、キーヤーはレバーが握られたままだと
思って出し続けます。次の場合に届きません。

- 押したまま別のアプリに切り替えた、ブラウザの外でボタンを離した
- 通知やダイアログに焦点を取られた
- タッチで、押した側と反対の半分まで指を滑らせて離した

**ウィンドウが焦点を失った時点で、押されている扱いのレバーはすべて離します。**
タッチは押した場所で側を決め、離した場所では決め直しません。

塞ぎ忘れた経路が残っている場合に備えて、**10 秒以上ずっと押されたままなら
自動で止めます**。いちばん遅い 5 WPM でも短点 40 個分にあたるので、ふつうの
打鍵が切られることはありません。止めたときは打面の下に断り書きが出ます。
余分に入った符号は「打ち直す」（`Esc`）で消せます。

### まずチュートリアルを

パネル先頭に **13 手順のチュートリアル**があります。実際に打って条件を満たすと
自動で次に進みます。

**初めはたたんであります。**「開く」を押してください。使い方が分かっている人に
毎回 1 画面ぶん押しのけられては、課題まで届くのにスクロールが要るためです。

1. パドルとエレクトロニックキーヤー
2. 短点を連続で出す
3. 長点を連続で出す
4. 1 文字打ってみる — A（・－）
5. 逆の順で — N（－・）
6. スクイーズ（両方を握る）
7. モード A と B の違い
8. 速度（WPM）の合わせ方
9. ウェイトの調整
10. 右手用と左手用
11. 語を打つ — CQ
12. 自局のコールサインを打つ
13. 基本は以上です

### 設定

**利き手** — パドルを同じ向きに置いたまま、右手で操作すると左のレバーに親指が、
左手で操作すると右のレバーに親指が当たります。CW では親指を短点に割り当てるのが
一般的なため、左手で打つ場合は短点と長点の割り当てが逆になります。

「親指側を長点にする」と組み合わせると、4 通りから選べます。

| 利き手 | 親指 | 左ボタン | 右ボタン |
|---|---|---|---|
| 右手用 | 短点 | 短点 | 長点 |
| 左手用 | 短点 | 長点 | 短点 |
| 右手用 | 長点 | 長点 | 短点 |
| 左手用 | 長点 | 短点 | 長点 |

**キーヤーモード**

| モード | 動作 |
|---|---|
| アイアンビック B | 両方を離した後にもう 1 要素送出する。多くの市販キーヤーの既定値 |
| アイアンビック A | 余分な要素を出さない。離した時点で送出中の要素を最後に停止 |
| ウルティマチック | 両押しでは後から押した側が優先され、連続送出される |
| 縦振り電鍵 | 左ボタンのみ。押した長さで短点・長点を判定する |

**ウェイト**（35〜65%）— 音を出している時間と休んでいる時間の比率です。
50% が標準。上げると重く、下げると軽い響きになります。全体の速度は変わりません。
実際の交信では 45〜55% に収めるのが無難です。

**送信音の高さ**（400〜1000 Hz）— 打鍵の側音の高さです。受信音の高さ
（設定・記録タブの「側音の高さ」）とは独立しているので、実際の運用と同じように
受信と送信で違う音程にできます。交信シミュレーターで自分の送信を再生するときも
この高さで鳴ります。

**速度**（5〜28 WPM）— まず正確に打てる速度まで落としてください。
速く打ち崩すより、遅くても崩れないほうが相手に届きます。

上限を 28 WPM にしてあるのは、パドルを手で操作して崩れずに打てる範囲に
練習を収めるためです。コンテスト運用の「自局速度」も同じ上限で頭打ちになります
（相手局の速度はこの上限とは別で、それより速い局も出てきます）。

**画面全体でパドル入力を受け付けます。** このタブを開いている間は、パドル欄の外を
クリックしても打電できます（ボタン・入力欄・リンクの上は通常のクリックとして
動きます）。設定ではなく、初めからそうなっています。打つたびに打面まで
マウスを運ばせるのでは練習にならないためです。他のタブを開いている間は、
パドル欄の中だけが打面です。

### 課題と採点

「課題」でコールサイン・略語・定型文などの手本を出し、それを打ちます。

### 100点＋（間隔まで手本どおり）

文字の採点は**語の切れ目を見ません**。手が一瞬止まっただけで語間が入って
しまうので、そこまで採点すると符号そのものの正誤が見えなくなるためです。

そのうえで、**語の切れ目まで手本どおりに打てたときは「100点＋」**として
別格に表示します。`CQ` が `C Q` に割れていなければ合格、という見方です。
文字がすべて合っていても語の切れ目が違えば 100% どまりです。

そのときは、**どの語が割れた（つながった）のか**を名指しします。たとえば
`BEGINNER` を 2 語に分けて打ってしまったときは「`BEGINNER` を `BE` `GINNER` に
割っています」と出て、その下に語ごとの突き合わせが並びます。割れた語だけに
色が付き、切れ目の位置に縦棒が立つので、どこで間が空いたのかが分かります。

> **`=` と `<BT>` は同じ符号です。** どちらも `-...-` なので、手本の `=` を
> `<BT>` と解読しても差になりません（`+` と `<AR>`、`(` と `<KN>` も同様）。
> 文字がすべて合っているのに 100点＋ にならないときは、この表記の違いでは
> なく語の切れ目が原因です。名指しされた語を見てください。

**100点＋ が出るまでにかかった時間**も一緒に表示します。

#### 押さずに採点される

**手本どおりに打ち切った時点で、「採点する」を押さなくても自動で採点します。**
設定ではなく、初めからそうなっています。照合が通るのは 100点＋ のときだけなので、
途中で誤って採点が走ることはありません。外したときはこれまでどおり
「採点する」を押してください。

#### 「かかった時間」の意味

計るのは **1 回の打鍵にかかった時間ではありません**。**その課題に挑み始めて
から 100点＋ が出るまで**の時間です。考えていた時間も、外してやり直した
時間も、すべて含みます。

計測の起点は次のとおりです。

| | 起点 |
|---|---|
| 1 回目 | **課題が出た時点** |
| 2 回目以降 | **100点＋ を出したあと、最初に「打ち直す」を押した時点** |

**途中で外しても、そこでは数え直しません。** たとえば 3 回外して 4 回目に
100点＋ が出たなら、外した 3 回ぶんも含めた通算時間が記録されます。
失敗のたびに 0 に戻していては、最後の 1 回ぶんしか計らないことになり、
「挑み始めてからどれだけで出せたか」が分からなくなるためです。

計測が止まるのは**打ち終わった瞬間**です。解読が確定するのは最後の符号から
文字間の長さ（短点 2.4 個分）が過ぎたあとで、「採点する」を押すのはさらに
そのあとですが、その間は打鍵時間に含めません。自動採点でも手押しでも
同じ物差しなので、記録表の数字はそのまま見比べられます。

記録は 1 つの課題につき **5 回まで**表に残り、いちばん速かった回が
色付きになります。次の課題に進むと数え直します。同じ課題を繰り返して
時間が縮んでいくかを見てください。

前の記録より速く出せたときは、**「自己ベスト更新」**の札が付きます
（1 回目は比べる相手がいないので付きません）。

#### 出たときの祝い

間隔までそろうのは狙って出せるものではないので、出たときははっきり
分かるようにしてあります。ファンファーレが鳴り、「100点＋」が跳ねて出て、
記録表に加わった行が一瞬光ります。

祝い方は **10 種類**あります（**設定・記録 →「100点＋ の祝い方」**）。
見た目も音も種類ごとに違います。

初めの設定は**「おまかせ」**で、100点＋ が出るたびに 10 種類から選び直します。
何が出るか分からないほうが飽きないためです。続けて同じものは出ません。
決め打ちしたいときは、一覧から種類を選んでください。

「見本を見る」を押せば、100点＋ を出さずにその場で確かめられます。おまかせの
ときは、押すたびに違う祝い方が出て、どれが出たか名前が添えられます。

| | 祝い方 | 出るもの |
|---|---|---|
| 1 | 紙吹雪 | 「100点＋」から色紙が扇形に散る |
| 2 | 花火 | 三か所で時間差の光の玉が開く |
| 3 | 合格スタンプ | 「合格」の印が勢いよく捺され、採点欄が一度揺れる |
| 4 | 表彰 | 金メダルがせり上がり、採点欄が金色の枠になる |
| 5 | 電光掲示板 | 「100点＋」が一文字ずつ点灯し、枠を光が回る |
| 6 | モールスで祝う | `FB`（素晴らしい）を符号で光らせ、符号の音で鳴らす |
| 7 | Ｓメーター振り切れ | 針が一気に振り切れて S9+60 で止まる |
| 8 | 桜と朱印 | 朱の丸印が捺され、花びらが舞い落ちる |
| 9 | レトロゲーム | 「PERFECT!!」が飛び出し、画面が短く揺れる |
| 10 | 静かに | 光がゆっくり一度だけ横切る（粒も揺れも出しません） |

音の高さは**打鍵側音を土台**にしています。側音を 700 Hz から動かしている
人でも、ファンファーレだけ調子が外れて聞こえないようにするためです。
音量は画面の音量つまみに従います。

OS で「視差効果を減らす／アニメーションを減らす」を有効にしている場合は、
**飾りと動きは出さず**、色と音だけで祝います。

### 交信の定型文と話題

「種類」で**交信の定型文**を選ぶと、隣に「話題」が出ます。
実際の交信で打たれる言い回しを話題ごとにまとめてあり、全部で 111 文あります。

| 話題 | 例 |
|---|---|
| 呼び出し・応答 | `CQ CQ CQ DE JA1ABC JA1ABC K` |
| あいさつ・気持ちを伝える | `GE DR OM = GLD TO WRK U` |
| 基本の交換（RST・名前・QTH） | `UR RST 599 599 = NAME TARO TARO` |
| 天気 | `WX MOSTLY SUNNY = TEMP ABT 22 C` |
| 時刻 | `QTR HR 1430 JST` |
| 場所・地理 | `MY QTH TOKYO = ABT 50 KM N OF TOKYO` |
| 電波の状況 | `UR SIGS 579 HR = SOME QRN` |
| フェージング | `UR SIG QSB DEEP = PSE RPT NAME` |
| 締めくくり | `TNX QSO = HPE CUAGN ES 73` |
| 聞き返し・トラブル | `SRI OM PSE RPT ALL AFTER RST` |

**おまかせ**にすると全話題から無作為に出ます。ひとつの話題に絞ると、
その言い回しを繰り返し打てるので、覚えたい話題を集中して練習できます。

文中の `{ME}` `{NAME}` `{QTH}` `{RIG}` `{PWR}` `{ANT}` にあたる部分は、
「設定・記録」に入れた自局の情報に差し替わります。相手のコールサインは
毎回無作為に作られます。

手本に Q 符号や略語が含まれるときは、**その下に短い意味が並びます**。
何を送ろうとしているのか分からないまま打つことにならないようにするためです。
手本の中の語も種類ごとに色分けされ、マウスを乗せると詳しい説明が出ます。
コールサインと数字は見れば分かるので、意味は付けていません。

**説明には、実際の符号を添えてあります。** 意味だけ分かっても打てないためです。

| 語 | 説明 |
|---|---|
| `FER` | 〜のために (for)　・・－・　・　・－・ |
| `DE` | 〜から（こちらは）　－・・　・ |
| `=` | 区切り（BT）— 話題の切れ目　－・・・－ |

文字ごとに区切って並べてあるので、どこで手を止めるかも読み取れます。
符号は用語一覧・マウスを乗せたときの説明・初心者モードの実況解説の
すべてに付きます。

打った符号の下に、操作が 3 つ並びます。

| ボタン | 動き |
|---|---|
| 採点する | 打った符号と手本を文字単位で照合します |
| 打ち直す | 打った符号を消して、同じ課題をやり直します（`Esc` でも同じ） |
| 次に進む | **採点せずに**次の課題へ移ります |

**「次に進む」は常に押せます。** 手応えが無かった打鍵をわざわざ採点に通す
必要はないので、採点を挟まずに次へ行けるようにしてあります。
打ちかけでも押せます（打った符号と採点結果はまとめて片付きます）。
自由練習には次の課題が無いので、そのときだけ押せません。

課題の種類を変えたいときは、上の「新しい課題」から選び直してください。

**語の間隔は採点に含めません。**打鍵の解読では、手が一瞬止まっただけで
語の切れ目が入ってしまうためです。採点するのは符号そのものの正誤だけで、
差分の表示には手本の語の切れ目を残してあります。

**照合は文字の見た目ではなく、符号で行います。** 表記が違っても符号が同じものは、
打てば区別が付かないからです。`=` と `<BT>` はどちらも －・・・－ なので、
手本が `=` のところを `<BT>` と解読されても正解として数えます
（`+` と `<AR>`、`(` と `<KN>` も同じ扱いです）。

- 緑 — 一致
- 赤の破線の囲み — 打ち漏らし
- 橙の波線 — 余分・誤り

「自由練習」を選ぶと手本なしで、打った符号の解読結果だけが表示されます。

解読できない符号は `＊` で表示されます。文字の区切りは手を止めた時間で
判断しているので、文字と文字の間は短点 3 個分ほど止めてください。

## 9. CW 交信サポート

無線機の受信音からモールスを解読し、相手の情報（コール・RST・名前・QTH）を
拾って、次に送る文の候補を出します。取った内容はそのままログ帳へ登録でき、
受信・送信のやり取りは交信記録として一緒に保存されます。

### つなぎ方

無線機の受信音を、この端末のマイクに聞かせるだけでも動きます。
確実なのはオーディオケーブルやインターフェース（無線機のスピーカー出力・
データ端子 → 端末のライン入力）です。

1. 「マイクを開く」を押して、ブラウザにマイクの使用を許可する
2. 相手の信号が鳴っているときに「いちばん強い音に合わせる」を押すと、
   トーン周波数が自動で合います（手でつまみを回しても構いません）
3. 解読された文字が受信欄に流れます。速度（WPM）は自動で追従します

### 相手の情報と返答の候補

解読した内容から、相手のコールサイン（`DE` の次の語）・もらった RST
（`UR 599` の 599。`5NN` は 599 に直します）・名前（`NAME` / `OP` の次）・
QTH が自動で埋まります。取り違えたら手で直せて、直した値が登録に使われます。

交信の段階（CQ を聞いた → 呼ばれた → レポート交換 → 締め）を追いかけて、
それに合った返答の候補を出します。候補を選ぶと送信欄に入り、
直してから送れます。

### 送信 — まずは自分の電鍵で

**「自分のパドルで打つ」**が基本の使い方です。候補を選ぶと手本とモールス表記が
出るので、それを見ながら右のパドル欄（またはキーボードの `Z` / `X`）で
自分で打ちます。「照合して記録する」を押すと手本との差分が出て、
**実際に打った内容**（手本ではありません）が交信記録に残ります。
打ち直しは `Esc` です。パドルの側音はこの端末の音声出力から出るので、
音声インターフェース（＋VOX）でつないでいれば、そのまま電波として乗ります。

慣れないうちは、返答の内容を考えることと符号を打つことを同時にやると
手が止まりがちです。候補を目で追いながら打つことに集中できるので、
実際の交信に出る不安を減らせます。

**「自動送信」**は、この端末から**キーイングされたトーン音**を出します。
無線機のマイク端子・データ端子へ音声としてつなぐ（SSB モード＋VOX など）か、
シリアルキーイング（下記）で電鍵端子を直接叩きます。速度はパドル欄の
送信速度と同じです。

**自動応答（実験的）**は、相手が自分を呼んできたときに最初の候補を自動で
送ります。送る前に 2 秒の予告が出て、その間にチェックを外せば止まります。
既定はオフです。

> **電波を出す前に。** 送信は必ず免許の範囲で、監視しながら行ってください。
> 自動応答も、オペレーターが付いていることが前提の補助機能です。

### シリアルキーイング（実験的）

USB シリアルの DTR / RTS を上げ下げして、キーイング回路（フォトカプラなど）
ごしに無線機の電鍵端子を叩きます。昔からある「COM ポートキーイング」と
同じ方式で、Chrome 系ブラウザだけが対応しています。
接続すると「自動送信」でトーン音と同時に電鍵も動きます。
実機での検証はまだ行えていないため、実験的な扱いです。

### ログ帳への登録

「この交信をログ帳へ登録」で、拾った情報（コール・RST・名前・QTH・周波数）と
交信記録がそのまま 1 件になります。「次の交信へ」で情報と記録をクリアして
次の相手に備えます。

## 10. ログ帳

実際の交信を記録する台帳です。練習の成績（設定・記録タブ）とは別に保存されます。

### 登録

日時・コールサイン・周波数・モード・RST・名前・QTH・JCC/JCG・QSL・備考を
入れて「登録する」を押します。よく使う欄は入れやすくしてあります。

- **日時**は JST で入れます（保存は UTC で行い、ADIF もそのまま正しく出ます）。
  「今」を押せば現在時刻が入ります
- **周波数**を入れるとバンドが自動で決まります（7.010 → 7MHz）
- **登録後も周波数・モード・RST は残ります。** 同じバンドで続けてログを
  付けるとき、入れ直さずに済むようにするためです

**同じ局をもう一度呼ぶと、交信歴が出ます。** 「この局とは 3 回交信しています
（前回 …）」のように表示され、名前・QTH・JCC が空欄なら前回の値で埋まります。

### JCC・JCG 検索

JARL の市郡区番号リスト（都道府県 47・市 890・郡 586・区 207 件、消滅済みを含む）を
収録しています。番号の前方一致でも、市郡区名（漢字・ローマ字）でも引けます。

**QTH は都道府県から書きます。** JARL の表は種類ごとに書き方が違い、市と郡は
「札幌」「阿寒」のように素の名前だけ、区は「北海道札幌市中央区」と県から
書いてあるものと「西」だけのものが混じっています。そのままログに入れると
どこの市区か分からなくなるので、次の形にそろえてから入れます。

| 番号 | 表の名前 | ログに入る形 |
|---|---|---|
| `0101` | 札幌 | 北海道札幌市 |
| `01001` | 阿寒 | 北海道阿寒郡 |
| `010101` | 北海道札幌市中央区 | 北海道札幌市中央区 |
| `430103` | 西 | 熊本県熊本市西区 |
| `2102` | 四日市 | 三重県四日市市 |

検索結果もこの形で出るので、**「熊本市」「北海道」のように都道府県や市の名前でも
引けます**。

結果を選ぶと、登録フォームの **JCC 欄と QTH 欄の両方**に入ります。QTH に何か
書いてあっても置き換えます。選び直したのに前の地名が残っていては、直した
つもりで直っていないログができてしまうためです。

**「現在地から探す」**を押すと、ブラウザの位置情報から近い市郡を距離順に
並べます（許可を求められます）。移動運用先で自分の JCC / JCG を調べるのに
便利です。政令指定都市が候補に出たときは、その市の区番号も一緒に並びます。

収録している座標は各市郡の代表点（GeoNames のデータと突き合わせて
市 790・郡 340・東京特別区 23 件）なので、**境界の近くでは隣の市郡が先に
出ることがあります**。「これで決まり」ではなく「近い候補から選ぶ」ための
並びです。

消滅した市郡区の番号も収録しているので（「消滅」と表示）、古いログの
番号も引けます。市町村合併で番号は変わっていくので、見つからない・
合わないと感じたら JARL が公表している最新の市郡区番号リストと
突き合わせてください。

### 一覧・編集・削除

新しい順に並びます。検索欄はコール・名前・QTH・JCC・備考を横断して探し、
バンドとモードでも絞り込めます。時刻表示は JST と UTC を切り替えられます。

「編集」で登録フォームに呼び出して直し、「削除」で消します。
交信サポートで保存した交信記録がある行には「記録」ボタンが出て、
受信・送信のやり取りをそのまま読み返せます。

### 集計

総交信数・ユニーク局数・JCC / JCG ワークド数・QSL 受領数と、
バンド別・モード別の内訳が出ます。区番号（6 桁）での交信は
その市の JCC としても数えます。

### 書き出し・取り込み

- **ADIF** — ログソフト（HAMLOG・Logger32 など）や QSL 転送サービスと
  やり取りできる標準形式です。日時は UTC、バンドは 40m 表記で出ます。
  JCC は `APP_CWTRAINING_JCC` フィールドに入れてあります
- **CSV** — 表計算ソフト向けです。交信サポートの交信記録も含めて往復できます

ログはこの端末のブラウザ（localStorage）にだけ保存されます。
**ブラウザのデータを消すとログも消えるので、ときどき書き出して控えを
取ってください。**

## 13. 設定・記録

### 音の設定

| 項目 | 範囲 | 内容 |
|---|---|---|
| 側音の高さ | 400〜1000 Hz | 受信音の音程。600〜700 Hz が一般的。送信音はパドル送信タブで別に設定 |
| 空電 QRN | 0〜100% | ざーっという雑音 |
| フェージング QSB | 0〜100% | 信号の浮き沈み |
| 混信 QRM | 0〜100% | 別の信号の混入 |
| 側音の波形 | サイン/三角/矩形 | 音色の好みで。矩形は硬い音になります |
| キーイングの立ち上がり | 2/5/8 ms | 短いほどカチッと、長いほど柔らかい鳴り方 |

QRN・QSB・QRM は、ドリルや交信シミュレーターに悪条件を加えるためのものです。
最初は 0 のまま、慣れてきたら少しずつ上げてください。
（コンテスト運用のバンドコンディションは、コンテストタブ側で個別に設定します）

### 表示の設定

- **再生中に本文を表示する** — 答えが見えるので、練習ではオフにしてください
- **初心者モード** — 送信中の Q 符号・略語をリアルタイムで解説します。
  受信中も語の意味が出るため、聞き取りの答えが部分的に見えます。
  実力を試すときはオフにしてください

### 学習の記録

ドリル・交信・送信・コンテストの成績が集計されます。

**上達の推移** には、ドリル正答率・コッホ法レベル・交信/送信成績の
小さな折れ線が表示されます（練習 3 回以上で出現）。点に触れると値が出ます。

**苦手な文字**は、**聞き取り**と**パドル入力**に分けて並びます。
耳で取れない文字と手で打てない文字は別物だからです。それぞれ 5 回以上
出てきた文字のうち正答率の低いものが並びます。

- **聞き取り** — 聞き取りドリルの書き取りから数えます。
  「この文字を集中練習する」で、その文字を重点的に混ぜたドリルが始まります
- **パドル入力** — パドル送信の採点と、交信シミュレーターの実技
  （「この内容で送信して次へ」で確定した打鍵）から数えます
「この文字を集中練習する」を押すと、その場で重点ドリルが始まります。

記録はこの端末のブラウザ内（localStorage）にのみ保存されます。
外部には一切送信されません。

**別の端末・ブラウザへ移すには**、「記録を書き出す」で JSON ファイルを保存し、
移動先で「記録を読み込む」を押してそのファイルを選びます。
設定・成績・自己ベストがまとめて移ります。

「記録を消去する」で全部消えます。取り消せません。

## 14. 速度の考え方

CW 学習で最も大事な考え方なので、独立した章にしています。

### 2 つの速度

**文字速度（char WPM）** — 一つ一つの文字を打つ速さ
**実効速度（effective WPM）** — 文字間・語間を含めた、全体としての速さ

このアプリは ARRL 方式のファーンズワース・タイミングを使っており、
**各文字は速いまま、文字間と語間だけを広げます**。

例えば文字速度 20 WPM・実効速度 10 WPM なら、`A` という文字自体は
20 WPM の速さで「ト・ツー」と鳴りますが、次の文字までの間が長く空くため、
全体としては 10 WPM のペースになります。

### なぜこの方式なのか

初心者がやりがちな失敗は、**全体をゆっくりにして覚えること**です。
5 WPM で覚えた `A` の音は、20 WPM の `A` とは別の音に聞こえます。
そのため速度を上げるたびに覚え直しになり、あるところで頭打ちになります。

文字速度を最初から高く保てば、覚えるのは 1 種類の音だけで済みます。
考える時間は文字間の空白で確保します。慣れてきたらその空白を詰めていけば、
文字の聞こえ方は変えずに速度だけを上げられます。

### 具体的な進め方

1. 文字速度を **20 WPM 以上**に設定し、以後は動かしません
2. 実効速度を、余裕をもって取れる速さ（最初は 5〜8 WPM）に下げます
3. その速度で正答率 90% を安定して超えたら、実効速度を 1〜2 WPM 上げます
4. 実効速度が文字速度に追いついたら、両方を一緒に上げていきます

焦って文字速度を下げないことが、遠回りに見えて最短です。

| 語 | 意味 | 使い方 |
|---|---|---|
| `DR` / `OM` | 親愛なる／相手への敬称 | `GE DR OM` |

| `WUD` | 〜したいのですが | `I WUD LIKE TO WRK U AGN` |
| `C` | はい・そのとおり | `C BK` |
| `MOM` / `AS` | 少しお待ちください | `MOM PSE` |

| 言い方 | 意味 |
|---|---|
| `SOLID CPI` / `SOLID CPI NW` | 完全にコピーできています |
| `GUD CPI AGN` | 今回も良好に取れています |
| `UR SIG LOUD ES CLR` | 非常に強く、かつ明瞭に届いています |
| `CUTTING THRU QRM` | 混信を突き抜けて届いています |

台本では**自分が出したレポートと辻褄が合う**ものだけを選びます。
599 を送っておいて「混信を突き抜けて」では話が合わないためです。

## 16. 困ったとき

### 画面が真っ白で何も出ない

`index.html` をダブルクリックして開いた場合に起こります。
アドレス欄が `file://` で始まっていたらこれが原因です。

[1. アプリを開く](#1-アプリを開く)の方法 A（公開ページ）か
方法 B（簡易サーバー）で開き直してください。

### 音が出ない

- **まずボタンをひとつ押してください。** ブラウザは利用者の操作があるまで
  音を鳴らせません
- 画面上部の「音量」が 0 になっていないか確認してください
- 端末側の音量・消音設定を確認してください
- **iPhone / iPad は本体側面のサイレントスイッチを確認してください。**
  これが入っていると、音量を上げてもブラウザの音は鳴りません。
  スマートフォンで音が出ないときは、まずここが原因です
- 「■ 停止」を押した直後は再生が止まっています。もう一度再生してください

### パドルの反応が遅い・打った符号が抜ける

打鍵の側音は、押してから **6 ミリ秒後**に鳴るよう予約しています。それ以上に
遅れて感じるときは、次の順に確認してください。

**1. Bluetooth のイヤホン・スピーカーを使っていませんか。**
これが最も多い原因です。Bluetooth は音の伝送に **150〜300 ミリ秒**かかる製品が
あり、短点 1 つ（20 WPM で 60 ミリ秒）より長くなります。こうなると、打った音が
返ってくる前に次を打つことになり、まともに打てません。**有線のイヤホンか
本体スピーカーに変えてください。** アプリ側では短くできない遅れです。

**2. 他のタブや別のアプリが重くありませんか。**
画面の描画などでブラウザが一瞬固まると、その間の符号が鳴り損ねます。
重いページを閉じてから試してください。

**3. 送信速度が速すぎませんか。**
自分の耳と手が追いつく速さまで、パドル欄の「送信速度」を下げてください。

なお、**打った符号が文字として表示されるまでには少し間があります**。これは
遅延ではなく、モールスの決まりです。文字の切れ目は「短点 3 個分の無音」で
決まるので、打ち終わってからその時間が過ぎるまで、まだ続きがあるのか
終わったのかを決められません（20 WPM で約 0.14 秒）。

### 速すぎて全く取れない

画面上部の**実効速度**を下げてください。文字速度は下げないでください
（理由は[14. 速度の考え方](#14-速度の考え方)）。

聞き取りドリルなら、レベルを下げて文字数を減らすのも有効です。

### パドル（マウス）が反応しない

- **パドル送信**タブを開いていれば、画面のどこでも打電できます
  （ボタンや入力欄の上を除く）
- 他のタブを開いているときは、画面右のパドル欄の中だけが打面です
- キーボードの `Z` / `X` は、入力欄やボタンに焦点があると効きません。
  パドル欄をクリックしてから押してください
- 短点と長点が逆なら、「利き手」の設定を確認してください

### 右クリックでメニューが出てしまう

パドル欄の上では右クリックメニューを抑止しています。**パドル送信**タブを
開いている間は画面全体で抑止されます。他のタブでは、パドル欄の外で
右クリックすると通常どおりメニューが出ます。

### 送信速度を変えても打鍵の速さが変わらない

キーヤーモードが**縦振り電鍵**になっていないか確認してください。
縦振りモードでは符号の長さは押した時間そのもので決まるため、
送信速度の設定は音に反映されません（短点・長点の判定しきい値にだけ使われます）。
アイアンビック A / B またはウルティマチックに切り替えると反映されます。
チュートリアル中は、この状態になると注意と「戻す」ボタンが表示されます。

### 打った符号が `＊` になる

その符号に対応する文字が無い、という意味です。多くは次の原因です。

- 要素を打ちすぎている（短点を押しっぱなしにして 6 個以上出ているなど）
- 文字の途中で間が空きすぎ、2 文字に分割された
- 文字と文字の間が短すぎ、1 文字につながった

文字の間は短点 3 個分ほど止めるのが目安です。

### コンテストで誰も応答してくれない

- 打ち込んだコールサインが、呼んでいる局のどれとも近くない可能性があります。
  `F7`（`?`）を送ると、呼んでいた局がもう一度名乗ります
- 待たせすぎた局は諦めて去ります。`F1` で CQ を出し直してください

### 設定や記録が消えた

設定と記録はブラウザの localStorage に保存されています。次の場合は消えます。

- ブラウザの閲覧データ（サイトデータ・Cookie）を削除した
- プライベートブラウジング／シークレットウィンドウで使っている
- 別のブラウザ、別の端末で開いた

「記録を書き出す」で残したファイルがあれば、「記録を読み込む」で復元できます。

### 画面が窮屈で見づらい

横幅が 760 ピクセルより広いと、右側をパドル欄が占めます。
1000 ピクセル以上にすると本文にも余裕が出ます。ブラウザの表示倍率を
下げるのも有効です。

760 ピクセル以下では自動的に 1 列になり、パドルは下から出す引き出しに
変わります。**スマートフォンで窮屈なときは、引き出しを ✕ で畳んでください。**

### 音が途中で止まったまま動かない

一時停止したままになっていないか、画面上部のボタンを確認してください。
「▶ 再開」と出ていれば一時停止中です。もう一度押すと続きから鳴ります。
